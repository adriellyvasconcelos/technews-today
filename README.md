# 🌐 TechNews Today

Portal de notícias sobre tecnologia desenvolvido com HTML5 e CSS3, como parte do desafio de Desenvolvimento Web.

## 📌 Sobre o projeto

O TechNews Today apresenta notícias e conteúdos sobre o mundo da tecnologia, utilizando HTML semântico e um design moderno com tema escuro.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Glassmorphism
- Media Queries para responsividade

## ✨ Funcionalidades

- Cabeçalho com efeito de vidro fosco.
- Título com texto em gradiente.
- Notícia em destaque com efeito ao passar o mouse.
- Seção expansível com `details` e `summary`.
- Vídeo do YouTube incorporado.
- Formulário de newsletter com campos obrigatórios.
- Layout responsivo para dispositivos móveis.
- Rodapé com informações de contato.

## 📂 Estrutura do projeto

```text
technews-today/

└── README.md
```

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `desafio10a.html` no navegador.
4. Confira o layout e os estilos aplicados pelo CSS.

## 🎯 Objetivo

Praticar a estruturação de páginas com HTML semântico e a estilização com CSS moderno, incluindo gradientes, efeitos visuais, CSS Grid e responsividade.
